# Caption archive branding

New editable clean archives should contain the creator's picture/effects, but not the platform watermark added for a free export. Today archive replay includes that mark and restyle finalization applies it again. Add an optional internal platform marker to watermark operations emitted by the router/gateway/worker. Archive replay skips only explicitly marked platform branding. Ordinary watermark operations, even with identical text, and embedded source marks remain unchanged.

The final export still applies the reservation-derived entitlement: free marked once, credit-funded no added platform mark. This does not remove already embedded marks or retrofit old archives. Keep intermediate clean objects private. Test real archived frames and explicit creator mark preservation, then exercise free-to-free and free-to-paid caption editing through real Linux rendering, audio hashes and decode checks.
